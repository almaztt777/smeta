# Правила для ИИ-агента

Проект: «Смета за 5 минут» (см. `README.md`).

## Порядок работы

1. Работать только внутри этой папки проекта.
2. Перед любыми изменениями прочитать текущие файлы проекта.
3. Делать только ту функцию, о которой просят. Не трогать лишнего и не ломать то, что уже работает.
4. После работы перечислить изменённые файлы и объяснить, как проверить результат.

## Технологии

- Только обычные HTML, CSS и JavaScript.
- Без npm, сборщиков и фреймворков.
- Без внешних ресурсов: никаких CDN, внешних шрифтов, библиотек и картинок из интернета.

## Данные и приватность

- Данные пользователя остаются в браузере (например, в `localStorage`).
- Ничего не отправлять в интернет: никаких запросов к серверам, аналитики и счётчиков.

## Удобство

- Понятные подписи у всех полей и кнопок (`<label>`, понятный текст кнопок).
- Поля ввода и кнопки — не меньше 44px по высоте и ширине.
- Всё должно работать с клавиатуры: переход по Tab, нажатие Enter и пробела, видимый фокус.
- Интерфейс должен быть удобным на телефоне: адаптивная вёрстка, нет горизонтальной прокрутки.

## Деньги и числа

- Суммы показывать с пробелами между тысячами и знаком тенге: `15 000 ₸`, `1 250 000 ₸`.
- Пустые и неверные числа считать нулём.
- Никогда не показывать `NaN`, `undefined` и `Infinity`.

## Git и публикация

- Не запускать git-команды (commit, push и другие) без прямой просьбы пользователя.
- Ничего не публиковать и не выкладывать без прямой просьбы пользователя.
