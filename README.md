# Смета за 5 минут

Веб-приложение, в котором можно быстро собрать смету или коммерческое предложение и сохранить его в PDF.

## Для кого

- **Предприниматели** — быстро подготовить коммерческое предложение (КП) для клиента.
- **Офисные сотрудники** — составить смету закупки или отчёт о расходах для руководителя.

Регистрация и интернет не нужны. Все данные остаются в вашем браузере.

## Файлы

| Файл         | За что отвечает                                                                 |
|--------------|---------------------------------------------------------------------------------|
| `index.html` | Структура страницы: заголовок, таблица позиций, поля ввода, кнопки, итог.       |
| `styles.css` | Внешний вид: шрифты, цвета, отступы, адаптация под телефон, вид при печати в PDF. |
| `script.js`  | Логика: добавление и удаление строк, подсчёт сумм и итога, форматирование денег. |

## Как открыть

Дважды щёлкните по файлу `index.html` — он откроется в браузере. Ничего устанавливать не нужно.

## Как проверить

1. Откройте `index.html`.
2. Добавьте две позиции:
   - количество **2**, цена **15 000**;
   - количество **1**, цена **8 000**.
3. Итог должен быть **38 000 ₸** (2 × 15 000 + 1 × 8 000 = 30 000 + 8 000).
4. Очистите любое поле или введите в него буквы: сумма считается как 0, а надписи `NaN` нигде нет.
